## 背景・目的

既存のFAQサイト（`index.html` / `style.css`）に、Bobのブランド要素（ロゴ・配色）を取り入れ、ライト/ダークの表示テーマを選べるようにする。

## 現在の挙動

* ヘッダーはタイトルと説明文のみで、ロゴはない。
* 配色は青系（プライマリ `#3b82f6`、ヘッダーグラデーション `#1e3a8a → #3b82f6`）。
* ダークテーマはない。

## 期待する挙動

1. ヘッダー左上に `bob.svg` が表示される。
2. ロゴをクリックすると https://www.ibm.com/products/bob が新しいタブで開く。
3. サイトのテーマカラーが `bob.svg` の配色（青 `#0f62fe` / 紫 `#a56eff`）になる。
4. ヘッダー右上のトグルボタンでライト/ダークを手動で切り替えられる。選択はリロード後も維持される。

## 対象範囲・対象外

### 対象範囲

* `index.html`: ヘッダーへのロゴ・リンク・テーマトグルボタンの追加、テーマ切替JSの追加
* `style.css`: CSS変数の配色変更、ダークテーマ用変数、ロゴ・トグルのスタイル追加

### 対象外

* FAQ内容の変更
* 検索・カテゴリ絞り込み・アコーディオンのロジック変更
* `bob.svg` 自体の変更
* OS設定（prefers-color-scheme）への自動追従
* 外部CDN・外部ライブラリの使用

## 利用者・影響システム

* FAQサイト閲覧者（Webブラウザ）

## 主な仕様

### ロゴ

* `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer">` で `<img src="bob.svg" alt="IBM Bob">` を囲む
* ヘッダー左上に配置
* サイズ: 48px（768px以下は40px）

### テーマカラー

* プライマリ色: `#0f62fe`（ボタン、アクティブ状態、フォーカスで統一）
* アクセント色: `#a56eff`
* ヘッダー背景: `#0f62fe → #a56eff` のグラデーション
* ライトテーマのグレー系は `bob.svg` の `#f4f4f4` / `#e0e0e0` / `#262626` に寄せる

### ダークテーマ

* ヘッダー右上のトグルボタンで手動切替
* 初期値はライト（OS設定には追従しない）
* 選択は `localStorage` に保存し、再訪時に復元する
* `<html data-theme="dark">` を付与し、CSS変数を上書きして実現する

## 制約・非機能要件

* 外部ライブラリ・CDN・外部フォント不使用
* 既存のレスポンシブ対応（768px）とモダンブラウザ対応を維持
* トグルボタンはキーボード操作可能とし、`aria-label` を付与する

## UI・画面仕様

### 対象画面

* FAQトップページ（`index.html`）のヘッダー部分と全体の配色

### 画面構成・表示項目

* ヘッダー左上: Bobロゴ（リンク付き）
* ヘッダー右上: テーマ切替トグルボタン
* ヘッダー中央: タイトル「よくある質問」と説明文（既存）
* それ以降（検索バー、カテゴリボタン、FAQセクション、フッター）は既存構成のまま

### 操作・画面遷移

* ロゴクリック → 外部サイトを新しいタブで開く
* トグルクリック → ライト/ダークを切り替え、`localStorage` に保存

### 表示状態

* 初期表示: ライトテーマ（`localStorage` に保存値があればそれを復元）
* ダークテーマ: 検索バー、カテゴリボタン、アコーディオン、0件メッセージ、フッターを含む全要素が読みやすい配色で表示される

### 入力・バリデーション

* 変更なし

### デザイン要件

* `bob.svg` の配色（`#0f62fe` / `#a56eff` / `#262626` / `#e0e0e0` / `#f4f4f4`）に統一
* 既存のレイアウトとシステムフォントを維持
* ダーク背景上でもロゴが視認できること
