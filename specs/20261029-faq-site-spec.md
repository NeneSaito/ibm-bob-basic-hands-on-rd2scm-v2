## 背景・目的

`qa.md` に記載されたFAQコンテンツを、バックエンドなしの日本語FAQサイトとして公開するための静的HTMLページを新規作成する。

## 現在の挙動

FAQコンテンツは `qa.md` のMarkdownファイルにのみ存在し、Webブラウザで直接閲覧できる形式になっていない。

## 期待する挙動

`index.html` をブラウザで開くと、日本語に翻訳されたFAQがアコーディオン形式で表示される。キーワード検索・カテゴリ絞り込みが可能で、バックエンドなしで完全に動作する。

## 対象範囲・対象外

### 対象範囲

* `index.html` の新規作成（HTML構造・FAQコンテンツ・JavaScript）
* `style.css` の新規作成（レイアウト・デザイン・アニメーション）

### 対象外

* バックエンド処理
* ビルドツール・フレームワーク
* 既存ファイルの変更
* 外部CDN・外部ライブラリの使用

## 利用者・影響システム

* FAQサイト閲覧者（Webブラウザ）

## 主な仕様

* `qa.md` の全FAQ（4カテゴリ・合計17Q&A）を日本語に翻訳して掲載
  * カテゴリ: 一般 / 使い方 / 高度な機能 / トラブルシューティング
* アコーディオン形式（クリックで回答を開閉）
* キーワード検索機能（質問・回答テキストをリアルタイムフィルタリング）
* カテゴリ絞り込み機能（ボタンクリックで対象カテゴリのみ表示）
* 検索とカテゴリ絞り込みの組み合わせが可能
* 検索結果0件の場合、「該当するFAQが見つかりませんでした」などのメッセージを表示
* 外部依存なし（純粋なHTML / CSS / JavaScript）

## 制約・非機能要件

* 外部ライブラリ・CDN不使用
* PC・スマートフォン両対応（レスポンシブ）
* モダンブラウザで動作すること（Chrome / Firefox / Safari / Edge 最新版）

## UI・画面仕様

### 対象画面

* FAQトップページ（`index.html` 1ページ）

### 画面構成・表示項目

1. **ヘッダー:** サイトタイトル（「よくある質問」）
2. **検索バー:** テキスト入力フィールド（プレースホルダー: 「キーワードで検索...」）
3. **カテゴリ絞り込みボタン:** 「すべて」「一般」「使い方」「高度な機能」「トラブルシューティング」
4. **FAQセクション（カテゴリ別）:**
   * カテゴリ見出し
   * 各Q&Aのアコーディオン（質問ヘッダー + 回答パネル）

### 操作・画面遷移

* 質問ヘッダーをクリック → 回答パネルが開閉（アニメーション付き）
* 検索バーに文字入力 → 質問・回答テキストをリアルタイムフィルタリング
* カテゴリボタンをクリック → 対象カテゴリのセクションのみ表示
* 検索とカテゴリ絞り込みは同時に適用可能

### 表示状態

* **初期表示:** 全アコーディオンが閉じた状態、「すべて」カテゴリボタンがアクティブ
* **検索中:** 条件に合致するQ&Aのみ表示
* **0件:** 「該当するFAQが見つかりませんでした」のメッセージを表示
* **カテゴリ絞り込み中:** 選択カテゴリのセクションのみ表示

### 入力・バリデーション

* 検索バーのみ（特別なバリデーションなし）

### デザイン要件

* モダンなデザイン
* アコーディオン開閉にCSSトランジションアニメーション
* レスポンシブ対応（モバイルファースト）
* 外部フォント不使用（システムフォント）
