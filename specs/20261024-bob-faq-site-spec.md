## 背景・目的

## 主な仕様

### データ

* `faq-data.js` はグローバル変数 `FAQ_DATA` を定義する。
* 各項目は `{ id, category, question, answer }` を持つ。
  * `category` は「全般」「使い方」「高度な機能」「トラブルシューティング」のいずれか。
  * `answer` は段落・箇条書きを表現できる構造とする(詳細は実装計画書で決定する)。
* 項目の並びは `qa.md` と同じ順序とする。

### カテゴリと件数(`qa.md` に基づく)

| カテゴリ | 原文見出し | 件数 |
| --- | --- | --- |
| 全般 | General | 5 |
| 使い方 | Usage | 8 |
| 高度な機能 | Advanced Features | 2 |
| トラブルシューティング | Troubleshooting | 2 |
| 合計 | | 17 |

> 注: 事前の現状理解では「全19問」と提示したが、`qa.md` の `###` 見出しを集計した結果、17問であった。

### 機能

1. キーワード検索
   * 質問文と回答文を対象に、部分一致で絞り込む。
   * 大文字小文字を区別しない。前後の空白は除去する。
   * 入力のたびに即時反映する。空文字なら全件を対象とする。
2. カテゴリ絞り込み
   * 「すべて」と4カテゴリのボタンから1つを選択する。初期値は「すべて」。
   * 検索とカテゴリはAND条件で併用できる。
3. アコーディオン表示
   * 質問をクリック、またはEnter/Spaceキーで回答を開閉する。
   * 各項目は独立して開閉できる(複数同時に開ける)。
4. 件数表示
   * 絞り込み後の件数を表示する(例: 「17件」)。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみで実装する。
* `file://` で開いても動作する。`fetch` は使わず、`<script>` タグでデータを読み込む。
* 外部通信を行わない。外部CDN・外部フォントは使わない。
* セキュリティ: データは `textContent` 等で描画し、`innerHTML` にデータを埋め込まない。
* アクセシビリティ: キーボードのみで全操作が可能。`aria-expanded`、`aria-controls`、検索結果件数の `aria-live` を用いる。
* 対応ブラウザ: PC・スマートフォンの最新の主要ブラウザ。

## UI・画面仕様

### 対象画面

FAQトップの1画面のみ(`index.html`)。ページ遷移はない。

### 画面構成・表示項目

上から順に以下を配置する。

```text
+--------------------------------------------+
| Bob よくある質問                  (ヘッダー) |
+--------------------------------------------+
| [ キーワードで検索...                    ] |
| [すべて][全般][使い方][高度な機能][トラブル...] |
| 17件                                       |
+--------------------------------------------+
| ▶ Bobとは何ですか?                         |
| ▼ Bobはどのように動作しますか?              |
|    回答本文(段落・箇条書き)                 |
| ▶ ...                                      |
+--------------------------------------------+
| フッター                                   |
+--------------------------------------------+
```

* ヘッダー: 左にロゴ(リンク)とサイトタイトル「Bob よくある質問」、右にテーマ切り替えボタン。
* 検索ボックス: ラベル「キーワード検索」。プレースホルダーあり。
* カテゴリボタン: 「すべて」「全般」「使い方」「高度な機能」「トラブルシューティング」。選択中は見た目で区別する。
* 件数表示: 現在の表示件数。
* FAQ一覧: 質問(開閉ボタン)と回答本文。カテゴリ名を各項目に小さく表示する。
* フッター: 原本が `qa.md` であること、日本語訳であることを記載する。

### 操作・画面遷移

* 質問のクリック、Enter/Spaceで回答を開閉する。
* 検索入力で即時絞り込み。カテゴリボタン押下で絞り込み。両者はAND条件。
* Tabキーで検索ボックス、カテゴリボタン、各質問の順に移動できる。
* 画面遷移はない。

### 表示状態

* 初期表示: 全件表示、回答はすべて閉じた状態、カテゴリは「すべて」。
* 絞り込み後: 該当項目のみ表示し、件数表示を更新する。
* 空状態: 該当なしの場合、「該当する質問が見つかりませんでした」を表示する。
* 読み込み中・エラー: データを同梱するため発生しない。

### 入力・バリデーション

* 検索ボックスは自由入力。前後の空白を除去する。最大文字数の制限はない。
* 特殊文字(正規表現記号など)は文字列として扱い、正規表現として解釈しない。

### デザイン要件

* ライトテーマとダークテーマ(上記「追加改修」の配色)。
* ヘッダーはスマートフォン幅でもロゴ・タイトル・ボタンが収まる(折り返し可)。
* レスポンシブ対応(PC・スマートフォン)。スマートフォン幅ではカテゴリボタンを折り返す、または横スクロールなしで操作できるようにする。
* 既存のデザインシステムはないため、独自の最小限のスタイルを定義する。
* 文字色と背景色のコントラスト比はWCAG AA相当を目安とする。フォーカス表示を明確にする。

## リスク・懸念点

* 日本語訳はBobが行うため、訳文の正確性は利用者による確認が必要。
* 「checkpoints」「auto-approval」などの用語は訳語の揺れが起きやすい。訳語を統一する。
* 自動テストの仕組みはないため、検証は手動中心となる。
* `bob.svg` の輪郭は濃いグレー `#262626` のため、ダーク背景ではロゴの輪郭が見えにくい可能性がある。ロゴはそのまま表示し、実装後に確認して対応要否を判断する。
