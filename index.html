一般

Bob は AI を活用したコーディングアシスタントです。コードの作成・リファクタリング・さまざまなタスクの遂行を支援します。カスタムモードや独自の指示を追加することで、機能を拡張することもできます。
Bob は大規模言語モデル（LLM）を使用して、ユーザーのリクエストを理解し、アクションに変換します。具体的には以下のことができます。
  • プロジェクト内のファイルの読み書き
  • ターミナルでのコマンド実行
  • インターネットの閲覧（有効な場合）
  • Model Context Protocol（MCP）を通じた外部ツールの利用
チャットインターフェース上で指示を入力し、提案されたアクションを確認・承認しながら操作します。
Bob はさまざまなコーディングタスクをサポートします。
  • 自然言語の記述からのコード生成
  • 既存コードのリファクタリング
  • バグの修正
  • ドキュメントの作成
  • コードの説明
  • コードベースに関する質問への回答
  • 繰り返し作業の自動化
  • 新しいファイルやプロジェクトの作成
以下のデータは Bob で処理しないでください。
  • SPI（機密個人情報）
  • PHI（個人健康情報）
  • 輸出規制対象データ（ITAR、APP 等）
  • 規制対象の金融データ（銀行口座番号、PAN、非公開の財務情報）
Bob は強力なツールです。責任を持って使用してください。
  • Bob はミスをする可能性があります。 承認する前に、提案された変更を必ず確認してください。
  • Bob はコマンドを実行できます。 特に自動承認を有効にしている場合は、コマンドの実行を慎重に行ってください。

使い方

Bob のパネルを開き、チャットボックスにタスクを入力してください。何をしてほしいかを明確かつ具体的に記述するとより正確な結果が得られます。
チャット入力エリアのドロップダウンメニューから別のモードを選択するか、/ コマンドを使用して特定のモードに切り替えることができます。
ツールは Bob がシステムと対話するための仕組みです。Bob はタスクを完了するために適切なツールを自動的に選択して使用します。ツールを直接呼び出す必要はありません。各ツールの使用時には承認または却下を求めるプロンプトが表示されます。
コンテキストメンションは、ファイル・フォルダ・問題点など、プロジェクトに関する特定の情報を Bob に提供する方法です。@ 記号の後に対象を続けて指定します（例: @/src/file.ts、@problems）。
はい、Bob はコマンドを実行できます。コマンドの自動承認を有効にしていない限り、各コマンドの実行時に承認を求めるプロンプトが表示されます。コマンドの自動承認には十分注意してください。
Bob が提案したアクションを承認または却下することでフィードバックできます。また、フィードバックフィールドを使用して追加のコメントを入力することもできます。
はい、以下の方法で Bob をカスタマイズできます。
  • カスタム指示: 全モードまたはモードごとに適用される指示を追加できます。
  • カスタムモード: 独自のプロンプトとツール権限を持つモードを作成できます。
  • Bob ルール: プロジェクトルートの .bob/rules/ フォルダにMarkdownのルールファイルを作成することで、追加のガイドラインを提供できます。
  • 設定: 自動承認・差分編集など、さまざまな設定を調整できます。
はい、Bob には有効にするとアクションを自動的に承認するいくつかの設定があります。

高度な機能

MCP は Bob が外部サーバーと通信するためのプロトコルです。カスタムツールやリソースを追加することで、Bob の機能を拡張できます。
はい、独自のMCPサーバーを作成して、Bob にカスタム機能を追加することができます。

トラブルシューティング

以下をご確認ください。
  • APIキーが正しく、有効期限が切れていないことを確認してください。
  • インターネット接続を確認してください。
  • VS Code を再起動してみてください。
Bob は VS Code の組み込みファイル編集機能を使用しています。標準の「元に戻す」コマンド（Ctrl / Cmd + Z）で変更を取り消すことができます。チェックポイント機能を使用して、ファイルへの変更を特定の時点に戻すこともできます。
